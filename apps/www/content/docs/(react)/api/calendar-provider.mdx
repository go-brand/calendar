---
title: CalendarProvider
description: Share an item-agnostic controller with controls and view projections.
---

```tsx
const calendar = useCreateCalendar({ views: { month: true, week: true } })

return (
  <CalendarProvider calendar={calendar}>
    <CalendarControls />
    <Suspense fallback={<CalendarSkeleton />}>
      <ActiveView />
    </Suspense>
  </CalendarProvider>
)
```

Because the provider carries no data, controls stay mounted while a query-owning child view suspends.
