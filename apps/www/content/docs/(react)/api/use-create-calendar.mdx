---
title: useCreateCalendar
description: Create a calendar in a component, with or without its events.
---

```tsx
const calendar = useCreateCalendar({
  views: { month: true, week: true },
  defaultDate: Temporal.PlainDate.from('2026-07-10'),
  defaultView: 'month',
  timeZone: 'America/Asuncion',
  items: events,
  getDate: event => event.date,
})
```

With `items`, the result also has `activeView`, the current month, week, or day with your events on it. Without `items`, pass the calendar to `CalendarProvider` and build views with [`useCalendarView`](/docs/api/use-calendar-view).

| Option | |
| --- | --- |
| `views` | Required. `{ month: true }`, or `{ week: { dayStart, dayEnd, slotDuration } }` for custom hours. |
| `defaultDate`, `defaultView` | Starting values. |
| `date`, `onDateChange`, `view`, `onViewChange` | [Controlled state](/docs/controlled-state). |
| `timeZone` | IANA name. Defaults to the device timezone. |
| `weekStartsOn` | `1` (Monday) through `7` (Sunday). Defaults to the locale's first day. |
| `items`, `getDate`, `getStart` | Your events and where each one goes. |

Use the calendar from the current render; it can change between renders. When rendering on the server, pass the same `date`, `view`, and `timeZone` on the server and the client.
