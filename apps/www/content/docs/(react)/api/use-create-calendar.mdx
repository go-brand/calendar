---
title: useCreateCalendar
description: Create a controlled or uncontrolled item-agnostic controller, with optional simple-mode data.
---

```tsx
const calendar = useCreateCalendar({
  views: { month: true, week: true },
  defaultDate: Temporal.PlainDate.from('2026-07-10'),
  defaultView: 'month',
  timeZone: 'America/Asuncion',
  items: events,
  getDate: event => event.date,
})
```

With `items`, the return value includes the inferred `activeView`. Without `items`, it returns the item-agnostic controller used with `CalendarProvider` and `useCalendarView`.

Controlled props are `date`/`onDateChange` and `view`/`onViewChange`; uncontrolled initial props are `defaultDate` and `defaultView`.

Use the controller returned by the current render. Its identity and action identities are not guaranteed to stay stable; controlled props, navigation, timezone, and view geometry can replace it. Controlled changes remain proposals until the parent supplies the new value.

The item-bearing result can also be passed directly to core `buildMonthView`, `buildWeekView`, and `buildDayView` for configured views. Supply each projection's own items and accessors.

For server rendering and hydration, supply matching explicit date, view, and timezone inputs on the server and client.
