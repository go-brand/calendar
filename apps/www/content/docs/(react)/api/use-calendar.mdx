---
title: useCalendar
description: Read the calendar from CalendarProvider.
---

```tsx
function Toolbar() {
  const calendar = useCalendar()
  return (
    <button onClick={calendar.next}>{calendar.title()}</button>
  )
}
```

The component re-renders when the date or view changes. Event types belong to [`useCalendarView`](/docs/api/use-calendar-view), so `useCalendar` takes none.

You can also pass a calendar made with core `createCalendar` to the provider. Create it once, for example in `useState`, not on every render.
