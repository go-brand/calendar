---
title: React Calendar
description: Headless Temporal-first calendar state and view projections for React.
---

The common path is one hook with value-driven inference:

```tsx
const calendar = useCreateCalendar({
  views: { month: true, week: true },
  items: events,
  getDate: event => event.date,
  getStart: event => event.startsAt,
})

return <CalendarContent view={calendar.activeView} />
```

For Suspense composition, create the controller without items above the boundary and call `useCalendarView` inside each query-owning view component.
