---
title: View Models
description: Discriminated month, week, and day models with locally inferred items.
---

`MonthView<TItem>`, `WeekView<TItem>`, and `DayView<TItem>` are discriminated by their `name` field. `ActiveView<TViews, TItem>` narrows the union to the configured views.

The old `view` field remains as a deprecated alias for compatibility. New code should use `name`.

Timed week and day configuration uses `Temporal.PlainTime` for `dayStart`/`dayEnd` and `Temporal.Duration` for `slotDuration`.
