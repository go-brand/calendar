---
title: Your first calendar
description: Build a month calendar with navigation in one hook.
---

Turn on a view, pass your events, and say which date each event is on.

```tsx
import type { Temporal } from '@js-temporal/polyfill'
import { useCreateCalendar } from '@gobrand/react-calendar'

type Event = {
  id: string
  title: string
  date: Temporal.PlainDate
}

function Calendar({ events }: { events: Event[] }) {
  const calendar = useCreateCalendar({
    views: { month: true },
    items: events,
    getDate: event => event.date,
  })

  return (
    <section>
      <button onClick={calendar.previous}>Previous</button>
      <h2>{calendar.title()}</h2>
      <button onClick={calendar.next}>Next</button>
      {calendar.activeView.weeks.flat().map(day => (
        <div key={day.id}>
          {day.date.toString()}: {day.items.map(event => event.title).join(', ')}
        </div>
      ))}
    </section>
  )
}
```

TypeScript infers `Event` from `items`, and `activeView` is a month because month is the only view.

<CalendarPreview name="basic-month" />

The calendar keeps the date and view, moves with `previous()`, `next()`, and `today()`, gives you a localized `title()`, and builds the grid. Your app owns the markup, styles, and data fetching.

## Events with a start time

If your events have a `Temporal.ZonedDateTime` start, give `getDate` the date part:

```tsx
const calendar = useCreateCalendar({
  views: { month: true, week: true, day: true },
  timeZone: 'Europe/Madrid',
  items: events,
  getDate: event => event.startsAt.withTimeZone('Europe/Madrid').toPlainDate(),
  getStart: event => event.startsAt.withTimeZone('Europe/Madrid'),
})
```

`getStart` places events in the week and day time slots. Convert to the calendar's timezone first, so an event at 23:30 UTC lands on the right local day. More in [timezones](/docs/timezones-and-ranges).
