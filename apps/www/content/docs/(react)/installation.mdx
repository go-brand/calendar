---
title: Installation
description: Install GoBrand React Calendar.
---

```bash
pnpm add @gobrand/react-calendar @js-temporal/polyfill
```

It includes the core package and its types, and works with React 18 and 19.

Import `Temporal` from the polyfill:

```typescript
import { Temporal } from '@js-temporal/polyfill';

const launch = Temporal.PlainDate.from('2026-07-10');
const standup = Temporal.ZonedDateTime.from('2026-07-10T09:00[Europe/Madrid]');
```
