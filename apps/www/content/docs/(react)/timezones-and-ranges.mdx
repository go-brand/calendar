---
title: Timezones and visible ranges
description: Show the right day in every timezone and query exactly what is on screen.
---

Set the timezone once:

```tsx
const calendar = useCreateCalendar({
  views: { month: true, week: true },
  timeZone: 'America/New_York',
})
```

It decides the starting date, `today()`, `isToday`, and the visible range. Leave it out to use the device's timezone; set it when rendering on a server or showing someone else's calendar.

## Query what is on screen

`visibleRange` covers every date in the current view. Include `start`, exclude `end`:

```ts
const { start, end } = calendar.visibleRange

await db.event.findMany({
  where: {
    startsAt: { gte: start.toInstant(), lt: end.toInstant() },
  },
})
```

Both are local midnights, so a day that daylight saving makes 23 or 25 hours long is still exactly one day.

## Put events on the right day

The calendar's timezone does not convert your events. Convert each one to that timezone, then read the date and start from the same value:

```ts
import { Temporal } from '@js-temporal/polyfill';

const meeting = {
  title: 'Sync with Tokyo',
  start: Temporal.Instant.from('2026-07-10T23:30:00Z').toZonedDateTimeISO('Europe/Madrid'),
};
const getDate = (event: typeof meeting) => event.start.toPlainDate();
const getStart = (event: typeof meeting) => event.start;
// getDate(meeting).toString() === '2026-07-11'
// getStart(meeting).hour === 1
```

In UTC the meeting is on July 10. In a Madrid calendar it is on July 11 at 01:30, and that is where it shows up.
