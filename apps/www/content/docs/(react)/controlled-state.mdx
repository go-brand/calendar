---
title: Controlled state and routing
description: Keep the calendar's date and view in the URL or your own state.
---

Pass `date` and `view` to control them, like a React input. Use `defaultDate` and `defaultView` to set only the starting values.

| State | Controlled | Starting value only |
| --- | --- | --- |
| Date | `date` / `onDateChange` | `defaultDate` |
| View | `view` / `onViewChange` | `defaultView` |

```tsx
const calendar = useCreateCalendar({
  views: { month: true, week: true },
  date: search.date,
  view: search.view,
  onDateChange: date => navigate({ search: previous => ({ ...previous, date }) }),
  onViewChange: view => navigate({ search: previous => ({ ...previous, view }) }),
})
```

The calendar follows the props right away, so the browser's back and forward buttons just work.

## Use the current calendar

`useCreateCalendar` can return a new calendar object after a render, for example when the date, view, or timezone changes. Read it and its actions from the current render. To subscribe, depend on it:

```tsx
useEffect(() => calendar.subscribe(() => {
  console.log(calendar.date.toString());
}), [calendar]);
```
