---
title: Visible ranges
description: The start and end to query for the dates on screen.
---

`visibleRange` covers every date the current view shows, including the leading and trailing days of a month grid.

```ts
import { Temporal } from '@js-temporal/polyfill';
import { createCalendar } from '@gobrand/calendar-core';

const calendar = createCalendar({
  views: { month: true },
  date: Temporal.PlainDate.from('2026-03-15'),
  timeZone: 'America/New_York',
  weekStartsOn: 7,
});

const { start, end } = calendar.visibleRange;
start.toString(); // "2026-03-01T00:00:00-05:00[America/New_York]"
end.toString(); // "2026-04-05T00:00:00-04:00[America/New_York]"
```

Include `start` and exclude `end`:

```sql
WHERE starts_at >= :start AND starts_at < :end
```

Both are local midnights in the calendar's timezone, so a day that daylight saving makes 23 or 25 hours long is still one day. Use `.toInstant()` when your database stores UTC.
