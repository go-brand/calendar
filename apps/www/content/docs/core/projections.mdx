---
title: View Projections
description: Turn the calendar and your data into month, week, or day views.
---

`buildMonthView`, `buildWeekView`, and `buildDayView` place your items on dates. Each call takes its own items, so a month of booking counts and a week of full meetings can share one calendar.

```ts
import { Temporal } from '@js-temporal/polyfill';
import { buildWeekView, createCalendar } from '@gobrand/calendar-core';

const meetings = [
  {
    title: 'Design review',
    start: Temporal.ZonedDateTime.from('2026-07-08T10:30[Europe/Madrid]'),
  },
];

const calendar = createCalendar({
  views: { week: true },
  date: Temporal.PlainDate.from('2026-07-08'),
  timeZone: 'Europe/Madrid',
  weekStartsOn: 1,
});

const week = buildWeekView({
  calendar,
  items: meetings,
  getDate: (meeting) => meeting.start.toPlainDate(),
  getStart: (meeting) => meeting.start,
});

week.weekStart.toString(); // "2026-07-06"
week.days[2].items.length; // 1
week.days[2].timeSlots[10].items[0].title; // "Design review"
```

- `getDate` returns the `Temporal.PlainDate` an item belongs to. It is required when you pass `items`.
- `getStart` returns a `Temporal.ZonedDateTime` and places the item in a time slot. Add it for week and day views with timed events.
- Without `items`, you get the empty grid, which is all a date picker needs.

The calendar's timezone does not convert your items. Convert each event to that timezone first, then derive both accessors from it; see [timezones](/docs/timezones-and-ranges).
