## getWeekdays

Weekday names in the order your calendar shows them. `1` starts on Monday, `7` on Sunday.

```ts
import { getWeekdays } from '@gobrand/calendar-core';

getWeekdays(); // ["Mon", "Tue", "Wed", "Thu", "Fri", "Sat", "Sun"]
getWeekdays(7); // ["Sun", "Mon", "Tue", "Wed", "Thu", "Fri", "Sat"]
getWeekdays(1, 'es-ES', 'long'); // ["lunes", "martes", "miércoles", "jueves", "viernes", "sábado", "domingo"]
getWeekdays(7, 'en-US', 'narrow'); // ["S", "M", "T", "W", "T", "F", "S"]
```

Use the calendar's `weekStartsOn` so the header matches the grid.

## Everything else is Temporal

Calendar has no other helpers. Temporal already does the rest in one line:

| Task | Temporal |
| --- | --- |
| Month name | `month.toLocaleString('en-US', { month: 'long' })` |
| Time label | `time.toLocaleString('en-GB', { hour: '2-digit', minute: '2-digit' })` |
| Device timezone | `Temporal.Now.timeZoneId()` |
| Show a meeting in another timezone | `meeting.withTimeZone('Asia/Tokyo')` |
| Date and time to a meeting | `date.toZonedDateTime({ timeZone, plainTime: time })` |
| Next month, last week | `date.add({ months: 1 })`, `date.subtract({ weeks: 1 })` |

For formatting and arithmetic with date-fns names, see [Tiempo](https://tiempo.gobrand.app).
