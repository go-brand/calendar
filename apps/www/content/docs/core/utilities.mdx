## Layout Helpers

Pure Temporal geometry helpers for timed grids, multi-day headers, and custom drag-and-drop integrations. All helpers are headless and return normalized ratios or Temporal values so you stay in full control of markup and styling.

### layoutTimedEvents

Computes DST-safe normalized vertical geometry (`top`, `height` in `[0, 1]`) and side-by-side column indices (`column`, `columns`) for overlapping timed events on a given day.

```typescript
import { Temporal } from '@js-temporal/polyfill';
import { layoutTimedEvents } from '@gobrand/calendar-core';

const laid = layoutTimedEvents(events, {
  date: Temporal.PlainDate.from('2026-07-10'),
  getStart: (event) => event.start,
  getEnd: (event) => event.end,
  dayStart: Temporal.PlainTime.from('08:00'),
  dayEnd: Temporal.PlainTime.from('18:00'),
});

// Position with CSS percentages:
// top: `${entry.top * 100}%`
// height: `${entry.height * 100}%`
// left: `${(entry.column / entry.columns) * 100}%`
// width: `${(1 / entry.columns) * 100}%`
```

### layoutMultiDayEvents

Computes spanning bar positions (`startCol`, `span`), greedy vertical `row` tracks, and continuation flags (`continuesBefore`, `continuesAfter`) for multi-day events across a month row or week header.

```typescript
import { layoutMultiDayEvents } from '@gobrand/calendar-core';

const bars = layoutMultiDayEvents(events, {
  start: week[0].date,
  end: week[6].date,
  getStart: (event) => event.startDate,
  getEnd: (event) => event.endDate,
});
```

## DnD & Time Positioning

Use these helpers with `@dnd-kit/core`, Pragmatic Drag and Drop, or plain pointer events without shipping a drag-and-drop library inside your calendar engine.

### getTimePosition & snapTimeFromPosition

Map between `Temporal.PlainTime` / `ZonedDateTime` and normalized `[0, 1]` ratios for current-time indicators and pointer drop snapping:

```typescript
import { Temporal } from '@js-temporal/polyfill';
import { getTimePosition, snapTimeFromPosition } from '@gobrand/calendar-core';

const config = {
  dayStart: Temporal.PlainTime.from('08:00'),
  dayEnd: Temporal.PlainTime.from('18:00'),
  slotDuration: Temporal.Duration.from({ minutes: 30 }),
};

// Current-time indicator line (values outside [0, 1] are outside business hours)
const nowPos = getTimePosition(Temporal.Now.zonedDateTimeISO('UTC'), config);

// Snap a pointer Y offset to the nearest 30-minute slot
const snapped = snapTimeFromPosition((clientY - rect.top) / rect.height, config);
```

### moveEvent & resizeEvent

Update event boundaries cleanly while preserving exact elapsed duration (DST-safe via BigInt nanoseconds) and preventing inverted ranges:

```typescript
import { Temporal } from '@js-temporal/polyfill';
import { moveEvent, resizeEvent } from '@gobrand/calendar-core';

const moved = moveEvent(event.start, event.end, targetStart);
const resized = resizeEvent(
  event.start,
  event.end,
  nextEnd,
  Temporal.Duration.from({ minutes: 30 }),
);
```

## Formatting

### getWeekdays

Get localized weekday names in the correct order for your calendar header.

```typescript
import { getWeekdays } from '@gobrand/calendar-core';

getWeekdays();
// ["Mon", "Tue", "Wed", "Thu", "Fri", "Sat", "Sun"]

getWeekdays(7);                    // Sunday start
// ["Sun", "Mon", "Tue", "Wed", "Thu", "Fri", "Sat"]

getWeekdays(1, 'es-ES');           // Spanish
// ["lun", "mar", "mié", "jue", "vie", "sáb", "dom"]

getWeekdays(1, 'en-US', 'long');   // Full names
// ["Monday", "Tuesday", ...]

getWeekdays(7, 'en-US', 'narrow'); // Single letter
// ["S", "M", "T", "W", "T", "F", "S"]
```

**Signature:**
```typescript
function getWeekdays(
  weekStartsOn?: 1 | 2 | 3 | 4 | 5 | 6 | 7,
  locale?: string | string[],
  format?: 'long' | 'short' | 'narrow'
): string[];
```
