---
title: Installation
description: Install GoBrand Calendar Core.
---

```bash
pnpm add @gobrand/calendar-core @js-temporal/polyfill
```

Types are included. Import `Temporal` from the polyfill and pass Temporal values to the calendar:

```ts
import { Temporal } from '@js-temporal/polyfill';

const launch = Temporal.PlainDate.from('2026-07-10');
const standup = Temporal.ZonedDateTime.from('2026-07-10T09:00[Europe/Madrid]');
```

Using React? Install [`@gobrand/react-calendar`](/docs/installation) instead; it includes the core package.
