---
title: Calendar Core
description: Framework-agnostic Temporal controller and pure calendar projections.
---

```ts
import { createCalendar, buildMonthView } from '@gobrand/calendar-core'

const calendar = createCalendar({
  views: { month: true, week: true },
  date: Temporal.PlainDate.from('2026-07-10'),
  timeZone: 'America/Asuncion',
})

const month = buildMonthView({
  calendar,
  items: events,
  getDate: event => event.date,
})
```

Core never installs Temporal globally and consistently uses `@js-temporal/polyfill`.
